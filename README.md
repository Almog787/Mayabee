## ✨ תכונות מרכזיות באתר (Key Features)

1. **מפת סיור אינטראקטיבית ב-2D (litecanvas):**
   * סיור ויזואלי ב-6 מתחמי הגן: לב הכוורת, מתחם המשחקים, פינת היצירה, חדר האוכל, אזור השינה, והחצר המוצלת.
   * קופסאות מידע מפורטות לכל חדר הכוללות שעות, תקני בטיחות ודגשים פדגוגיים.

2. **טפסי פנייה והרשמה ישירים בווטסאפ:**
   * **טופס הרשמת הורים:** שילוב פרטי הילד/ה, גיל והערות עם יצירת קישור ווטסאפ מובנה לרותם.
   * **טופס דרושים וגיוס צוות:** הגשת מועמדות מהירה לנשות צוות וסייעות.

3. **שקיפות, נגישות ו-SEO מתקדם:**
   * מותאם במלאות לכללי נגישות (RTL, פונטים קריאים, ניגודיות גבוהה, תמיכה במקלדת).
   * כולל סכמות מובנות מבית Schema.org (`ChildCare` ו-`FAQPage`) לדירוג גבוה בגוגל.
   * מודאלים משפטיים: הצהרת נגישות, מדיניות פרטיות, תקנון הגן ודרכי הגעה.
